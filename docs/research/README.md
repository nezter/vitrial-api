# Research

Findings that informed a decision, disproved an assumption, or are not yet verified defects.

Format per file, named `{date}-{slug}.md`:

1. the question
2. the method — command run, output excerpt, real numbers
3. the conclusion — adopt / reject, and why

Once a finding is reproduced as a defect, move it to `trackers/vitrial-api-TRACKER.md` as
`VITR-V###` and link back here. A research finding is a claim with evidence; a defect is a
claim with a repro.

Keep tangents short. A research file longer than ~200 lines is two files.
