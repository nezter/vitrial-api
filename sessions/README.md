# Sessions

One note per working session. Name it `session-{YYYY-MM-DD}-{slug}.md` (e.g.
`session-2026-10-02-guardrails-audit.md`). Record what was attempted, what was found —
**especially dead ends** — what changed, and what remains. A note that records only successes
is incomplete. This is where "how we got here" lives; `trackers/` is where "where we are" lives.

Do not put seeds here. Seeds go in `memory-seeds/` and are harvested by memory_seed_service;
a session note is a human log, a seed is a continuity record.
